# PAU en 50 minuts

Entrenament guiat d’Història d’Espanya: **Entre moderats i progressistes (1833–1874)**.

Set fases que sumen 50 minuts, amb conceptes, comentari de fonts, tema, comparació XIX–XX, revisió i bitllet d’eixida.

Basat en el format PAU GVA 2026 verificat. És una pràctica adaptada, no un examen oficial ni un simulacre complet de 90 minuts.

Fonts i imatges de Vicens Vives / EduBook, seleccionades per a l’anàlisi educativa i atribuïdes als titulars originals. Models i consignes originals.

Consulta la [guia docent](guia-docent.md) i la [fitxa imprimible](fitxa-imprimible.html).

Web estàtic, sense compilació ni recollida de respostes al servidor. GitHub Pages: branca `main`, arrel del repositori.
